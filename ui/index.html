Модель Claude

Что можно без спроса

В голосовом режиме Claude не может переспросить разрешение: всё, что не отмечено, будет отклонено. Команды и правка файлов дают доступ к ПК любому, кто говорит рядом с устройством. Удаление, установку программ, выключение и непонятные (закодированные) команды сервер пропускает, только если ваша фраза в этот раз — явное «да». Фильтр неполный: это страховка, а не песочница.

Действия на компьютере

Команды PowerShell дают локальной модели почти полный доступ к ПК, а устройство слышит всех в комнате. Удаление, установка, выключение и закодированные команды отклоняются, но фильтр неполный — включайте, только если действительно нужно.
Движок не отвечает: . Запустите сервер движка (в LM Studio — вкладка Developer → Start Server) и загрузите модель.

Движок

LM Studio и Bionic запускаются сами, без окна. Если порт занят резервом Windows, будет выбран свободный.

Модель

Инструменты работают, если модель и движок поддерживают function calling (LM Studio, llama.cpp с --jinja, vLLM).
Ollama не отвечает по адресу . Запустите Ollama и обновите страницу.

Модель

Сервер сам запускает отдельную Ollama с вашей папкой моделей на порту 11435. Ваше приложение Ollama не затрагивается.
Управление устройством работает с моделями, которые умеют вызывать инструменты: Qwen 3, Qwen 2.5, Llama 3.1+, Mistral.

Скачать модель

RTX 3090 (24 ГБ) спокойно тянет модели до ~30B в сжатии q4.

Железо

Все технические детали устройства: дисплей, выводы, антенки и кнопки, выходы. Сохраняется в программе (hardware.json) и применяется на устройстве.

Если после смены дисплея или пинов экран не работает — включите устройство, удерживая кнопку BOOT (на плате zhengchen 1.54 — «громкость −»): оно загрузится с заводскими настройками, а вы исправите профиль здесь.

Токен вашего аккаунта (нужна подписка Плюс для полных треков). Как получить токен — описано в документации библиотеки yandex-music (раздел «Получение токена»). Токен хранится только на этом ПК.

Spotify

Нужен Spotify Premium. Скажите «включи Spotify», затем в приложении Spotify выберите колонку с этим именем — звук пойдёт на устройство.

Камера

Источник

Прошейте ESP32-CAM стандартным примером CameraWebServer (Arduino) — снимок берётся с адреса /capture.
Пины модуля OV2640/OV3660 задаются ниже и применяются при сохранении. На плате zhengchen 1.54 свободных выводов не хватает (нужно 14) — используйте ESP32-CAM.
Claude смотрит на снимок сам. Ollama и другим движкам нужна модель, понимающая изображения.
